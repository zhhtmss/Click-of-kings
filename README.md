# Click of Kings

Click of Kings - браузерная clicker-игра про развитие королевства через несколько эпох. Игрок зарабатывает ресурсы кликами, покупает улучшения, усиливает пассивный доход и постепенно открывает новые этапы цивилизации.

## Возможности

- кликерная механика с ростом силы клика;
- пассивный доход каждую секунду;
- магазин улучшений для кликов и автоматического дохода;
- дополнительные эффекты улучшений: множители, скидки и критические клики;
- 5 эпох с разными ресурсами, фонами, музыкой и коэффициентами прогресса;
- прогресс-бар перехода к следующей эпохе;
- сохранение прогресса в `localStorage`;
- переключатель звука и звуковые эффекты.

## Технологии

- HTML5
- CSS
- JavaScript
- Web Audio API
- `localStorage`

## Как запустить

Откройте файл `index.html` в браузере.

Дополнительная установка не нужна. Если браузер ограничивает воспроизведение аудио при открытии файла напрямую, запустите проект через локальный сервер:

```bash
python -m http.server 8000
```

После запуска откройте:

```text
http://localhost:8000
```

## Как играть

1. Нажимайте на главный объект в центре экрана, чтобы получать ресурс текущей эпохи.
2. Покупайте улучшения в боковых магазинах.
3. Повышайте силу клика и пассивный доход.
4. Выполняйте условия эпохи: накопите нужное количество ресурсов и купите требуемое число улучшений.
5. Переходите в следующую эпоху и открывайте новые бонусы.

## Сохранения

Прогресс автоматически сохраняется в браузере с помощью `localStorage` под ключом:

```text
click_of_kings_save
```

Чтобы сбросить сохранение, можно выполнить в консоли браузера:

```javascript
localStorage.removeItem("click_of_kings_save");
location.reload();
```
Более легче можно использовать кнопку ниже центральной картинки.

## Настройка игры

- Эпохи редактируются в `js/eras.js`.
- Улучшения редактируются в `js/upgrades.js`.
- Основные параметры кликов, дохода и автосохранения находятся в `js/game.js`.
- Внешний вид настраивается в файлах папки `css/`.
- Изображения, музыка и эффекты лежат в `assets/`.
